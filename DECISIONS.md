# Decisions

Answers to the build plan's open questions (2026-11-15).

| Question | Decision |
|---|---|
| Final date / crash version | None. Orgo Type is a general study tool, not built around one course's schedule. No exam-date mode in v1; it can return later as an optional setting. |
| Topic order | No textbook or course order to follow. Units follow the standard Orgo 2 carbonyl sequence: 0 why carbonyls react → 1 nucleophilic addition (aldehydes/ketones) → 2 acyl substitution (acids & derivatives) → 3 1,2 vs 1,4 → 4 enolates, with synthesis woven through. The Orgo 1 side deck (SN1/SN2/E1/E2, alcohols & ethers) is available from the start as a separate deck. |
| Name | Orgo Type (for now). |
| Firebase | A new, separate Firebase project (not Anatomy Type's). Needed in Phase 3. |
| Audience | Friend-only pilot first; club access later. |
